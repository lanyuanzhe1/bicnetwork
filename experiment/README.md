# 实验目录约定

每次实验单独建立 `experiment<日期或编号>/`，在该目录内保存 `code/`、`results/`、`README.md` 和 `报告.md`。不要把不同实验的结果混放或覆盖；模型、数据、指标口径和运行命令记录在各实验的 README 与报告中。

- [experiment1016](experiment1016_参数范围外推测试/README.md)：10 月 16 日新测试集对现有 BIC1 前向、逆向和代理闭环模型的评估。
- [experiment1019](experiment1019/README.md)：历史最优配置跑满 500 轮，并重新评估 10 月 16 日测试集。
