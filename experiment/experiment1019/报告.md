## 指标定义

对一组预测值 $\hat y_i$ 和真实值 $y_i$，共有 $N$ 个参与比较的标量：

$$\mathrm{MSE}=\frac{1}{N}\sum_{i=1}^{N}(\hat y_i-y_i)^2,$$

$$\mathrm{MAE}=\frac{1}{N}\sum_{i=1}^{N}|\hat y_i-y_i|.$$

光谱指标把所有样本的 1101 个频点一起平均；参数指标把样本与参数维度一起平均，逐列 MAE 则只在样本维度平均。BIC1 的参数归一化沿用旧训练集的最小值和最大值。闭环光谱指“真实谱 → 逆向网络预测参数 → 前向代理预测谱”，再与真实谱比较。它是代理闭环误差，不等于把预测结构重新送入 CST 的误差。

`Code/runs/bic1/forward_20261019_122946` 跑满 500 轮，最佳验证轮次仍为 186，最佳验证 MSE 为 0.003718530，内部测试光谱 MSE 为 0.003895612。新旧 `best.pth` 的 SHA-256 完全相同，说明继续训练并未得到更好的前向检查点。

## BIC1 直接逆向重训结果

`Code/runs/bic1/inverse_mlp_20261019_123524` 跑满 500 轮，最佳验证轮次为 204，最佳验证参数 MSE 为 0.021044305。相比旧 run 的 0.021296263，验证指标略降。内部测试参数 MSE 从 0.019955911 降到 0.018960146；代理闭环光谱 MSE 从 0.006024715 升到 0.006159870。因此当前改进只体现在参数目标，不能据此宣称闭环谱更准确。

## BIC1 tandem 重训结果

`Code/runs/bic1/tandem/tandem_20261019_124110` 跑满 500 轮，最佳验证轮次为 177，最佳验证总损失从 0.024628262 降到 0.024382637。内部测试参数 MSE 从 0.018199457 降到 0.016856618，代理闭环光谱 MSE 从 0.004861816 降到 0.004711841。这说明本次较长训练在旧分布的内部测试上给 tandem 带来小幅改善。

本次 BIC1 前向最佳权重与旧 run 完全相同，所以 10/16 前向指标也完全相同。两个新逆向模型在旧分布的内部测试上有所改善，但在 10/16 数据的参数与代理闭环光谱指标均略差。这是不同数据分布下的实际结果，不能用内部测试改善推断新数据也会改善。

具体看外推范围，旧 BIC1 训练数据的 A、B、L 分别只覆盖 5–15、40–70、30–60 µm；10/16 数据对应范围为 15–25、70–90、10–30 µm。本次 tandem 在新数据上预测的 A、B、L 范围仍约为 5.07–15.00、40.03–69.96、30.03–59.36 µm，未能输出新数据主要所在的范围。前向模型在旧范围重叠的 4 条样本上 MSE 为 0.001102，而在越界的 176 条样本上为 0.045129。这些观测支持“训练参数范围不覆盖新样本”是测试误差较大的主要原因；仅延长旧数据训练轮数无法解决这种外推问题。

完整逐样本结果见 `results/per_sample.csv`，预测数组见 `results/predictions.npz`，代表性谱线见 `results/spectra_examples.png`。每个新 run 的配置、500 轮损失和最佳检查点均在 `Code/runs/` 对应目录的 README 中。

## 解释范围

10/16 数据中只有 4/180 条结构参数完全位于旧 BIC1 训练范围；其余 176 条至少一列越界。因此独立测试主要考察外推，单靠消除早停不一定会显著改善误差。测试数据不参与调参和最佳轮次选择。

## 是否继续增加训练轮数

若验证集指标在接近最大轮数时仍持续刷新最佳值，可以提高 `max_epochs` 再训练，并继续按最低验证损失保存模型。判断训练是否还值得延长，应看验证集而非持续下降的训练损失；10/16 独立测试集也不能用来决定轮数。

| 模型 | 最佳验证轮次 | 最佳验证损失 | 第 500 轮验证损失 |
| --- | ---: | ---: | ---: |
| BIC0 前向 | 235 | 0.000795916 | 0.000926459 |
| BIC0 逆向 | 446 | 0.054346220 | 0.054636519 |
| BIC1 前向 | 186 | 0.003718530 | 0.003963229 |
| BIC1 直接逆向 | 204 | 0.021044305 | 0.023774247 |
| BIC1 tandem | 177 | 0.024382637 | 0.029322836 |

这五个模型在第 500 轮都未达到新的最佳验证损失；最接近边界的 BIC0 逆向也已有 54 轮未刷新。因此本次没有证据支持继续增加轮数。若未来某个模型到训练末段仍在刷新最佳值，延长训练时还需同步重新设定余弦学习率调度器的 `T_max`，不能只在现有 500 轮曲线后直接追加轮数。
