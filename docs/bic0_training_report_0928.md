## 技术细节

数据来自 `周期分类数据集/BIC-0/` 的同号 `PARA/para{i}.txt` 与 `TXT/{i}.txt`，编号 1–768。TXT/PARA 同号配对已由 CST 源数据验证，见 [`数据集分析报告.md` §5.1](../数据集分析报告.md)。五个变化参数分别按本类范围做 min-max 归一化；Y 全部为 0，原样保留；光谱幅值不额外归一化。每条谱为 0.5–1.3 THz 的 1101 个采样点。固定随机种子 42 的划分为训练 614、验证 76、测试 78，索引固化在 NPZ 中。

前向、逆向均为宽度 512、三个残差块的 MLP。逆向网络约有 215 万参数，训练目标为六列归一化参数的 MSE，包括 Y=0；没有加入前向闭环损失。闭环评估时，仅将逆向输出的**参数副本**中 Y 设为精确 0，再输入已训练的 BIC-0 前向模型，原始预测不被改写。前向 checkpoint 由 `Code/BIC0/inverse.yaml` 的 `evaluation.forward_run` 明确指定，避免误用旧全量数据模型。

数据预处理最初由用户使用 miniconda base 执行；模型训练及本报告的指标复算使用 conda `LLM` 环境。现行代码入口与配置见 [`Code/BIC0/README.md`](../Code/BIC0/README.md)；其中示例命令仍写 base Python，复现模型训练应改用 `/opt/homebrew/Caskroom/miniconda/base/envs/LLM/bin/python`。旧 `Code/configs/inverse_mlp.yaml` 不是本次 BIC-0 逆向运行配置。

## 遇到的问题与处理

第一轮逆向训练使用学习率 `0.001`。最佳验证参数 MSE 为 `0.2909286257`（第 7 轮），第 57 轮早停；保存的模型在多个变化参数上输出接近恒定的 0 或 1，属于输出饱和。该轮测试代理闭环光谱 MSE 为 `0.0589985773`，不能作为可用逆向基线。

将学习率改为 `0.0001`、其他训练配置保持不变后，最佳验证参数 MSE 降至 `0.0589668025`（第 130 轮）。第 180 轮早停正好对应连续 50 轮未刷新最优验证值，符合 `patience: 50` 的设定，不是训练脚本异常。后续三次相同配置、相同 seed 的运行与该轮损失及指标一致，不能视为三个独立随机种子的稳健性实验。

## 证据边界

代理闭环光谱 MSE 达到 `0.0011484418`，表示预测参数经**前向神经网络**重建的光谱与测试目标接近；它并非 CST 仿真误差。前向网络只在有限离散网格上训练，逆向网络却可输出连续参数，因此代理闭环结果不能保证这些参数在 CST 中产生相同光谱。测试目标也是现有仿真数据中的留出谱，尚不能代表任意理想目标谱的性能。

本项目最终目标是“理想光谱 → 结构参数 → CST 复算光谱”。现阶段既没有对预测结构做 CST 回验，也没有确定参数误差的最终汇总口径；不能据一个低闭环 MSE 宣称已完成实用逆向设计。
