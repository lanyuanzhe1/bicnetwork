## 1. 背景与目标

合作方（天大邹蝶/吴亮组）提供的 `Deeplearning/` 是一个 24 样本的教学 demo（4 参数 → R/T/A 三条谱的 MLP）。本项目在其思路之上，基于主数据集（`dataset/`，3838 个有效样本）构建**正式的实验管线**，服务逆向设计论文：

1. **前向网络**：结构参数 → S21 透射谱（替代 CST 仿真的快速代理模型）
2. **逆向网络（cVAE）**：目标谱 → 结构参数（论文核心，从零设计）
3. 前向网络同时充当逆向结果的"打分器"：cVAE 生成的候选结构经前向网络重构谱，与目标谱比对完成闭环验证

**明确排除**（本次范围外）：

- 结构图（FIG/）不作为任何网络的输入或输出（用户决定；且报告指出 38 对"图同谱不同"样本对图任务有害）
- CST 自动验证接口（VBA 宏等）——用户选择最小方案，CST 复核后续手动进行
- 外推测试集（经讨论否决，见 §7 决策记录）

## 2. 命名约定

遵循 demo（`dataload.py`）与领域文献（Liu et al. 2018; arXiv 2507.14761）的一致约定：

- **前向（forward）= 参数 → 谱**（沿物理因果方向：结构决定响应）
- **逆向（inverse）= 谱 → 参数**（从期望响应倒推结构）

代码、图表、论文中统一使用此约定，不得反过来。

## 3. 数据

### 3.1 数据源

- 参数：`dataset/PARA/para{id}.txt`，6 列数值，id ∈ [1, 3840]
- 光谱：`dataset/TXT/{id}.txt`，1101 个采样点，频率 0.5–1.3 THz 等间隔（步长 0.0008 THz），S21 线性幅度，值域约 [0.01, 1.0]
- id ↔ para ↔ 谱 按编号一一对应

### 3.2 参数空间（全因子网格，无重复）

| 参数 | 取值 | 水平数 |
|---|---|---|
| P1 | 110, 120, 130, 140 | 4 |
| P2 | 110, 120, 130, 140 | 4 |
| P3 | 5, 10, 15 | 3 |
| P4 | 40, 50, 60, 70 | 4 |
| P5 | 30, 40, 50, 60 | 4 |
| P6 | 0, 5, 10, 15, 20 | 5 |

4×4×3×4×4×5 = 3840。参数的物理含义/单位待向师姐确认（不影响管线开发）。

### 3.3 数据清洗

- **跳过 id 2532、2645**（TXT 谱文件缺失）→ 有效样本 3838
- 38 对"图同谱不同"样本：**保留**。弃用图像后，这些是参数↔谱完全合法的独立样本（参数不同、谱不同），不存在标签含糊问题
- 谱无需对齐/插值：频率网格完全一致

### 3.4 预处理

- **参数**：min-max 归一化到 [0,1]（按每个参数的网格水平端点）
- **谱**：不做 log、不再缩放（本就在 [0,1]，log 会在深谷（T→0.01）处放大数值噪声）
- **划分**：随机 8:1:1（训练 3070 / 验证 384 / 测试 384），**固定种子 42**，划分结果随 `data.npz` 固化保存，所有实验复用同一份划分

### 3.5 产出

`Code/data/processed/data.npz`：`X_params (3838,6) float32`、`Y_spec (3838,1101) float32`、`freq_grid (1101,)`、划分索引、id 列表。原始 TXT 读取经缓存只跑一次。

## 4. 前向网络

### 4.1 架构

全连接残差 MLP（PyTorch）：

```
输入 6 → Linear(6,512) → [ResidualBlock(512) × 3] → Linear(512,1101) → Sigmoid
ResidualBlock: Linear(512,512) → LayerNorm → GELU → Linear(512,512) → LayerNorm → GELU → +输入
```

- 参数量约 90 万，对 3070 训练样本是中等容量；若欠拟合/过拟合再调
- Sigmoid 输出匹配谱值域 [0,1]

### 4.2 训练

- 损失：MSE；优化器：AdamW(lr=1e-3, weight_decay=1e-4)；调度：cosine 退火
- batch=32，最多 500 epoch，early stopping（验证集 patience=50）
- 设备：Apple Silicon MPS（无则 CPU）；数据量小，单次训练预计几分钟
- 记录：train/val loss 曲线、最优 checkpoint 存 `Code/runs/forward_<时间戳>/`

### 4.3 评估

- 测试集 MSE、MAE、R²
- 物理指标：谐振谷频率误差（预测谱 vs 真实谱最深谷位置之差，THz）、谷深误差
- 出图：随机 4 例"真实谱 vs 预测谱"对比曲线

## 5. 逆向网络（cVAE）

### 5.1 架构

参考 arXiv 2507.14761（cVAE+筛选框架）与 tanzim-rahman/plasmonics-inverse-design 的全连接实现：

- **编码器** q(z|x,c)：输入 [参数 x(6) ∥ 谱 c(1101)] → 512 → 256 → 均值 μ 与 logσ²（各 16 维）
- **解码器** p(x|z,c)：输入 [z(16) ∥ c(1101)] → 512 → 256 → 输出参数 x̂(6)，Sigmoid（对应归一化参数区间）
- 隐变量维度 16：6 维参数的一对多自由度有限，16 足够且利于 KL 稳定

### 5.2 训练

- 损失：L = MSE(x, x̂) + β·KL(q(z|x,c) ∥ N(0,I))
- **β 退火**：前 30 epoch 从 0 线性升到 0.1，之后固定（防 KL 坍塌/后验失踪）
- 优化器/调度/设备同前向；batch=32，最多 500 epoch，early stopping patience=50
- **前提**：需先完成前向网络训练（评估闭环依赖它）

### 5.3 推理与评估（闭环）

对测试集每条目标谱：

1. cVAE 解码器采样 **K=50** 个候选参数（z ~ N(0,I)，条件为目标谱）
2. 全部候选经**前向网络**重构谱，与目标谱算 MSE
3. 取误差最小者（best-of-50）为该谱的逆向设计结果

指标：

- **主指标 — 谱重构误差**：best-of-50 候选的前向重构谱 vs 目标谱的 MSE（逆向设计论文标准：谱对上即成功，参数不必等于真值，一对多是合法解）
- **辅助指标 — 网格命中率**：best-of-50 参数反归一化后四舍五入到最近网格水平，与真值完全相同（6/6）的比例。预期偏低（一对多），仅作参考
- **多样性**：50 个候选的成对谱误差分布（验证 cVAE 确实学到多解而非坍塌到单点）
- 出图：随机 4 例"目标谱 vs 逆向→前向重构谱"对比 + 标注 best 候选参数

## 7. 关键决策记录

| 决策 | 结论 | 理由 |
|---|---|---|
| 输入模态 | 只用参数，弃用结构图 | 用户决定；且图像存在 38 对含糊样本与周期裁剪疑点 |
| 逆向方法 | cVAE（非 tandem/MDN） | 用户指定；能给出多解；参考 2507.14761 |
| 数据划分 | 随机 8:1:1，种子 42 | 外推测试集方案经讨论否决：它验证的是前向泛化而非逆向核心主张，且代价是 20% 数据；网格均匀，随机划分无泄漏风险 |
| CST 验证 | 不做自动接口，手动复核 | 用户选最小方案；师姐工程的参数化方式未知 |
| 谱预处理 | 不归一化（原生 [0,1]） | log 会在深谷放大噪声 |
| 命名 | 前向=参数→谱，逆向=谱→参数 | 与 demo 及文献一致 |

## 8. 风险与开放问题

1. **参数物理含义未确认**（P1–P6 对应哪些结构尺寸、单位）——不阻塞开发，论文写作前必须向师姐确认
2. **cVAE 一对多程度未知**：全因子网格 + 单条 S21 谱，谱→参数可能接近一对一，此时 cVAE 相对简单回归的优势不显；多样性指标（§5.3）用于诊断这一点。若确认接近一对一，论文叙事应强调 cVAE 的生成式框架与不确定性量化而非多解
3. **3838 样本对 1101 维输出仍偏少**：前向若过拟合，备选手段是数据增强（谱沿频率轴 ±1 点微移）或加 dropout，先按设计跑 baseline 看指标再定
4. **OneDrive 占位文件**：`dataset/` 未本地化的文件读取会超时，`data.py` 首次运行前需确保 TXT/PARA 已完全下载到本地
5. 训练结果的验收标准（测试集 MSE 阈值）先不设硬指标，baseline 跑出来后与合作方对齐预期

## 9. 验收标准

1. `data.py` 产出 `data.npz`，3838 样本、形状正确、划分可复现（种子 42 重跑一致）
2. 前向网络训练收敛，测试集评估指标与 4 例对比图产出
3. cVAE 训练收敛（重构损失下降、KL 不坍塌：KL 项不为 0 且 μ/σ 不退化）
4. best-of-50 闭环评估跑通，主/辅指标与对比图产出
5. 全部代码在 `Code/` 下，配置驱动（yaml），`runs/` 存产物；仓库 git 可追踪、大文件已忽略
