# BIC1 直接逆向与 tandem 对照（2026-09-29）

两组使用同一份 `data/processed/bic1.npz`，测试集 307 条、seed 42、宽度 512 和 3 个残差块的逆向 MLP、学习率 5e-5，以及同一个前向 checkpoint `runs/bic1/forward_20260929_101011/best.pth`。直接逆向只优化参数 MSE；tandem 优化参数 MSE 与前向代理光谱 MSE 的等权和。最佳 checkpoint 分别按各自的验证损失选取。

Tandem 第 119 轮达到最佳验证组合损失 0.024628，第 169 轮早停。测试集指标见 [本次运行结果](../../runs/bic1/tandem/tandem_20260929_233231/metrics.json)；训练各轮的参数、光谱及组合损失见同目录 `losses.csv`。前向模型在真实测试参数上的光谱 MSE 为 0.003896，可作为理解代理误差的参照，不能将它当作严格误差下限。

这是一组单 seed、单次划分和单个前向代理的对照。六参数全中率只是标签恢复诊断；代理闭环改进尚未经过 CST 验证，不能当作最终设计成功率。
